Setup: getting the QA build onto a device
  1. On the Mac, start the QA build. Vite prints a Network address such as http://192.168.1.20:4174/. 
    cd ~/Documents/buzzy-abc-garden && npm run qa
  2. On the device (same Wi-Fi), open that address with ?dev=perf on the end.
  3. Offline and install (section 9) need HTTPS: upload dist-e2e/ to a static HTTPS host and test from there.
  4. Before each device, clear the site's data so it behaves like a new child's. iOS: Settings → Safari → Advanced → Website Data. Android Chrome: site settings → Clear & reset.
  5. Console lines ([quality], [timing], errors): iPhone/iPad via Mac Safari → Develop → device; Android via chrome://inspect with USB debugging.
